This repository contains my coursework, implementations, notes, and problem-solving practice from an **Advanced Data Structures and Algorithms** course.

The goal of this repository is to build a deeper understanding of how algorithms work, why they are correct, and how their performance can be analyzed.

## Approach

For each algorithm, I aim to document:

1. **The problem** — What are we trying to solve?
2. **The idea** — How does the algorithm work?
3. **The implementation** — How does the pseudocode translate into code?
4. **The trace** — What happens step by step?
5. **Correctness** — Why does the algorithm produce the correct result?
6. **Complexity** — What are the time and space requirements?
7. **Testing** — Does the implementation work on different inputs?

## Example: Selection Algorithm

One example explored in this repository is the **kth order statistic** problem.

Instead of sorting an entire array to find one element, the selection algorithm uses partitioning to eliminate the portion of the array that cannot contain the desired element.

For example, if we want the element at index `k`, partitioning allows us to determine whether to continue searching on the left or right side.

This connects several important concepts:

* Quicksort partitioning
* Divide-and-conquer
* Recursion
* Order statistics
* Best-case and worst-case analysis
